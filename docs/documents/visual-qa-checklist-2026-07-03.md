# 2026-07-03 육안 테스트 체크리스트 캡처

> 캡처 기준: `docs/agent/todo.md`의 `7/2 QA 이후 수정한것들 육안 테스트` 섹션.
> 목적: 2026-07-02 QA 이후 RN에 반영했지만 아직 사용자가 직접 확인하지 않은 항목을 실기기/배포 앱 기준으로 한 번에 확인한다.

| 상태 | 항목 | 어디서 | 뭘 확인하나 |
| --- | --- | --- | --- |
| ⬜ | 언어 설정/영문 문구 전환 | 마이페이지 → 설정 → 언어 설정, 홈/모임/책이야기/마이페이지 주요 화면 | 한국어/영어 전환 후 앱 재진입에도 설정이 유지되고, 버튼/토스트/빈 상태/오류 문구에 번역 키가 그대로 노출되지 않음. |
| ⬜ | 모임 채팅 웹소켓 배포 앱 동작 | 모임 → 책장 → 정기모임 → 조 상세 → 채팅 FAB | 시뮬레이터가 아니라 배포 앱에서 조 채팅 접속, 최근 메시지 로드, 실시간 송수신, 재연결, 과거 메시지 더 불러오기가 정상이고 인증/권한 오류가 반복되지 않음. |
| ⬜ | 모임 수정 이름 중복확인 | 모임 상세 → 운영진 관리 → 모임 정보 수정 | 기존 이름은 바로 저장 가능, 새 이름은 중복확인 전 저장 차단, 중복 이름은 안내 문구로 차단, 사용 가능한 이름은 저장 후 상세/목록에 즉시 반영됨. |
| ⬜ | 모임 가입신청 폼 버튼/키보드 | 모임 탭 → 비공개 모임 카드 → 가입신청하기 | 폼 버튼이 `가입 신청하기`/`닫기`로 보이고, 닫기는 신청 없이 폼만 닫음. 신청 사유 입력 시 어떤 기기에서도 입력박스와 버튼이 키보드 위에 보임. |
| ⬜ | 책이야기 탭 무한스크롤 중복 요청 방지 | 책이야기 탭 → 하단까지 빠르게 스크롤 | 같은 커서 요청이 연속으로 중복 발사되지 않고, 429/요청 과다 오류 토스트가 반복되지 않음. 실패 시 하단 재시도 상태가 과하게 튀지 않음. |
| ⬜ | 앱 로그인 세션 유지 | 로그인한 상태 → 앱 백그라운드/재실행/약 1시간 후 재접속 | 로그인 상태가 의도치 않게 풀리지 않고, 앱 로그인 경로에서 refresh/restore 후 홈·마이페이지·인증 필요 API가 정상 동작함. |
| ⬜ | 알림 클릭 이동 경로 | 마이페이지/헤더 → 알림 전체보기 → 각 알림 클릭 | `LIKE`/`COMMENT`는 책이야기 상세, `FOLLOW`는 프로필, `JOIN_CLUB`은 모임 홈, `CLUB_MEETING_CREATED`는 정기모임/책장 상세, `CLUB_NOTICE_CREATED`는 공지 상세로 이동. 삭제/탈퇴 대상은 적절한 토스트로 처리됨. |
| ⬜ | 생성 시간 상대표기 갱신 | 알림 목록, 책이야기 목록/상세 등 `방금 전` 표시 화면 | 페이지 재진입/새로고침/포커스 복귀 시 `방금 전`이 현재 시각 기준으로 다시 계산되어 `n분 전` 등으로 바뀜. 오래 열린 화면에서도 과도하게 stale 하지 않음. |
| ⬜ | 마이페이지 신고 관리 매핑 | 마이페이지 → 설정 → 신고 관리 | 내가 신고한 대상 목록이 비어 있지 않게 표시되고, 신고 대상/사유/날짜가 올바르게 매핑됨. 신고 대상 프로필/콘텐츠 진입이 가능한 경우 정상 이동함. |
| ⬜ | 타인 프로필 책이야기 진입/복귀 | 다른 사람 프로필 → 책이야기 탭 → 책이야기 카드 클릭 | 책이야기 상세가 정상 열리고, 뒤로가기/닫기 시 엉뚱하게 책이야기 메인 탭으로 튕기지 않고 원래 타인 프로필 흐름으로 복귀함. |
| ⬜ | 마이페이지 프로필 편집 키보드/개행 | 마이페이지 → 프로필 편집 | 키보드가 열린 상태에서도 닉네임 중복확인/저장 버튼이 터치되고, 소개글 입력에서 엔터 개행이 가능하며 텍스트/하단 카운터가 잘리지 않음. |
| ⬜ | Android 공지 투표 옵션 터치/상단 여백 | Android → 모임 상세 → 운영진 관리 → 공지 작성 → 투표 | `실명`과 `중복 가능` 칩이 키보드 상태에서도 선택되고, 공지 작성 화면이 처음부터 아래로 밀려 보이지 않음. 투표 저장 payload가 의도한 옵션으로 반영됨. |
| ⬜ | 모임 정보 수정 문의하기 링크 | 모임 상세 → 운영진 관리 → 모임 정보 수정 → 문의하기 링크 | 기존 문의 링크가 수정 화면에 보이고, 링크 추가/수정/삭제 후 저장하면 모임 상세의 `문의하기` 모달에도 그대로 반영됨. 최대 4개/label 20자/link 100자 제한과 빈 링크 제외가 정상 동작함. |
| ⬜ | 소식 상세 제목/작성일/내용 배치 | 소식 탭 → 소식 상세 조회 | 히어로 이미지 위에 작성일이 겹치지 않고, 상세 본문 영역에서 `소식 제목` → `작성일` → `내용` 순서로 보임. 작성일 텍스트가 잘리지 않고 한국어/영어 전환 시 문구가 정상 표시됨. |
