# autoFocus 전수 감사 — 포커싱 UX 검토

> 작성일: 2026-05-08  
> 목적: 사용자가 의도적으로 여는 폼/화면에서 키보드 자동 진입(autoFocus) 적용 여부를 정리하고, 추가했을 때 UX가 좋아질지/나빠질지를 판단한다.

---

## 판단 기준

| 기호 | 의미 |
|------|------|
| ✅ 적용 완료 | 이미 autoFocus 적용 |
| ✅ 권장 | 사용자가 해당 화면을 열었을 때 바로 입력할 의도가 명확 → 추가 효과 있음 |
| ⚠️ 중립 | 입력 의도가 명확하지 않거나, 폼의 첫 번째 필드가 아님 → 상황에 따라 판단 |
| ❌ 불필요 | 여러 필드 중 중간 필드, 옵션 필드, 또는 사용자가 내용을 먼저 확인해야 하는 경우 |

---

## 1. AuthFlowScreen — 회원가입 / 로그인 플로우

각 step은 단계 버튼을 눌러 진입하는 **단일 목적 화면**. 첫 번째 필드에만 적용이 적절.

| 상태 | step | 필드 | 파일:라인 | 판단 이유 |
|------|------|------|-----------|-----------|
| ✅ 권장 | `login` | 아이디(이메일) | AuthFlowScreen:1238 | 로그인 화면 진입 시 첫 번째 필드, 바로 입력 |
| ❌ 불필요 | `login` | 비밀번호 | AuthFlowScreen:1247 | 아이디 다음 필드 — 아이디 autoFocus 시 불필요 |
| ✅ 권장 | `emailVerification` | 이메일 입력 | AuthFlowScreen:773 | step 진입 즉시 이메일 입력이 목적 |
| ⚠️ 중립 | `emailVerification` | 인증코드 | AuthFlowScreen:802 | 이메일 입력 후 코드 수신 대기 → 자동 노출되면 오히려 성급 |
| ✅ 권장 | `passwordSet` | 비밀번호 | AuthFlowScreen:869 | step 진입 즉시 입력 목적 |
| ❌ 불필요 | `passwordSet` | 비밀번호 확인 | AuthFlowScreen:891 | 두 번째 필드 |
| ✅ 권장 | `profileBasic` | 닉네임 | AuthFlowScreen:934 | 프로필 step의 첫 번째 필드 |
| ❌ 불필요 | `profileBasic` | 이름 | AuthFlowScreen:984 | 두 번째 필드 |
| ❌ 불필요 | `profileBasic` | 전화번호 | AuthFlowScreen:995 | 세 번째 필드 |
| ✅ 권장 | `findId` | 이름 | AuthFlowScreen:1162 | 아이디 찾기 첫 번째 필드 |
| ❌ 불필요 | `findId` | 전화번호 | AuthFlowScreen:1170 | 두 번째 필드 |
| ✅ 권장 | `resetPw` | 이메일 | AuthFlowScreen:1214 | 비밀번호 재발급 첫 번째 필드 |
