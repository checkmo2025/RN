## 🐛 버그 수정 (Bug Fixes)

1. **모임 카드 제목 잘림 해결** — 제목이 길어지면 '비공개' 태그가 잘려 보이던 문제를 flex 레이아웃 보정으로 해결해, 어떤 길이의 모임 이름에서도 태그가 온전히 노출됩니다.

2. **댓글 입력 시 키보드 가림 해결** — 책이야기 댓글 작성 중 키보드가 입력창을 가리던 문제를 iOS/Android별 키보드 오프셋 처리로 해결해, 입력 내용이 항상 보이도록 했습니다.

3. **기본 프로필 아이콘 깨짐 해결** — 일부 iOS 기기(Pro Max 등)에서 기본 프로필 이미지가 원형 밖으로 삐져나오던 문제를, SVG 직접 렌더링 방식 전환과 원형 클리핑 이중 안전장치로 모든 기기에서 정상 표시되도록 수정했습니다.

4. **마이페이지 동작 오류 해결** — 프로필 수정 저장 후 설정 화면이 자동으로 닫히지 않던 문제와 신고 내역 텍스트가 화면을 벗어나던 오버플로우 문제를 함께 수정했습니다.

5. **공유 링크 오류 해결** — 공유하기 URL 경로 오류(`/book-stories/` → `/stories/`)를 바로잡고, 공유 시 링크가 중복으로 노출되던 문제를 제거해 정상적인 공유가 가능합니다.

6. **약관 모달 스크롤 불가 해결** — 회원가입 약관 상세 모달 내부가 스크롤되지 않던 문제를 터치 영역 구조 조정으로 해결해, 전체 약관을 끝까지 확인할 수 있습니다.

7. **가입 직후 불필요한 오류 알림 차단** — 회원가입 직후 모임 정보를 불러오는 과정에서 의미 없는 오류 토스트(`CLUB_MEMBER_404`)가 노출되던 문제를 차단해 첫 진입 경험을 깔끔하게 했습니다.

## ✨ 기능 추가 (Features)

1. **앱 전반 스켈레톤 로딩 UI 도입** — 홈·소식·책이야기·모임·마이페이지·알림·책 검색·설정·프로필 등 **거의 모든 화면**에 로딩 중 콘텐츠 형태의 스켈레톤(shimmer)을 표시합니다. 단순 "불러오는 중…" 텍스트를 실제 레이아웃을 닮은 placeholder로 교체해, 체감 로딩 속도와 앱 완성도를 크게 끌어올렸습니다.

2. **책 검색 무한 스크롤** — 검색 결과의 '더보기' 버튼을 없애고, 스크롤이 하단에 닿으면 다음 결과를 자동으로 불러오는 무한 스크롤과 로딩 스피너를 적용해 검색 탐색 흐름을 매끄럽게 했습니다.

3. **댓글 바로 작성 포커싱** — 책이야기 피드에서 댓글 아이콘을 누르면 상세로 이동하면서 댓글 입력창에 자동으로 커서가 잡혀, 추가 동작 없이 곧바로 댓글을 작성할 수 있습니다.

4. **회원가입 이메일 인증** — 6자리 인증번호 기반 이메일 인증 단계를 추가했습니다. 재인증 초기화, 인증번호 자릿수 제한, 남은 시간 표시 등 실사용에 필요한 요소를 함께 갖췄습니다.

5. **비밀번호 조건 실시간 안내** — 비밀번호 입력 시 6~24자·영문 포함·특수문자 포함 조건의 충족 여부를 ✓/× 아이콘으로 실시간 표시해, 사용자가 규칙을 즉시 알 수 있도록 했습니다.

6. **네이티브 공유 시트** — 공유 방식을 클립보드 복사에서 OS 기본 공유 시트로 전환해, 카카오톡 등 외부 앱으로 한 번에 공유할 수 있는 표준적인 공유 경험을 제공합니다.

7. **Android 빌드/배포 설정 완비** — EAS 기반 Android 앱 번들(app-bundle) 빌드와 스토어 자동 제출(track/service account) 설정을 구성해, Android 배포 파이프라인을 갖췄습니다.

## ⚡ 개선 (Improvements)

1. **마이페이지 로딩 속도 개선** — 프로필·팔로우·책이야기·서재·모임 5개 데이터를 순차 호출에서 병렬 호출(`Promise.all`)로 전환해, 마이페이지 진입 시 로딩 시간을 단축했습니다.

2. **모임 화면 포커싱 정교화** — 모임 탭 전환과 책장 상세 진입 시 항상 적절한 위치(모임 이름 / `< 책장` 위치)가 화면 상단에 오도록 스크롤 포커싱을 통일하고 안정화해, 탭을 오갈 때의 화면 흔들림을 없앴습니다.

3. **회원가입 플로우 전면 정비** — 단계별 카드 크기·레이아웃을 통일하고, 가입 완료(6/6) 화면을 재배치했으며, 1~3단계 이탈 시 정보 손실을 막는 확인 모달을 추가해 가입 과정의 일관성과 안정감을 높였습니다.

4. **모달 디자인 토큰 통일** — 모달의 배경 투명도·최대 너비·모서리 둥글기를 공통 토큰(`dialog.ts`)으로 수렴해, 앱 전반의 모달이 동일한 시각 기준을 따르도록 정리했습니다.

5. **네이티브 Alert 전환** — 이메일 재인증·기본 프로필 확인 등 단순 확인 절차를 커스텀 모달에서 OS 기본 Alert로 전환해, 플랫폼 일관성과 접근성을 높이고 불필요한 상태 코드를 정리했습니다.

6. **댓글 입력창 자동 확장** — 입력 내용 길이에 따라 입력창 높이가 자동으로 늘어나도록(최소 48 / 최대 120) 개선해, 긴 댓글도 편하게 작성할 수 있습니다.

7. **책장 상세 자동 로딩** — 책장 상세 진입 시 데이터 캐시가 없으면 자동으로 불러오고, 첫 렌더에서 빈 화면 대신 로딩 문구를 먼저 표시해 매끄러운 진입 경험을 제공합니다.
