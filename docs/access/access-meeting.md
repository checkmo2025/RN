# 모임 검색 화면 접근 권한 (`MeetingScreen` — 루트)

## 역할 범위

| 역할 | 설명 |
|------|------|
| 사용자 | 회원가입 하지 않은 사람 |
| 멤버 | 회원가입을 한 사람 |
| 관리자 | 책모의 관리자 |

---

## 기능별 권한

| 기능 | 사용자 | 멤버 | 관리자 |
|------|:------:|:----:|:------:|
| 화면 진입 | ✅ | ✅ | ✅ |
| 모임 검색/필터 | ✅ | ✅ | ✅ |
| 모임 카드 조회 | ✅ | ✅ | ✅ |
| 모임 추천 목록 조회 | ❌ 로그인 유도 | ✅ | ✅ |
| 모임 홈 방문 (방문하기) | ✅ | ✅ | ✅ |
| 가입 신청 | ❌ 로그인 유도 | ✅ | ✅ |
| 내 모임 드롭다운 조회 | ❌ 미표시 | ✅ | ✅ |
| 모임 생성 | ❌ 로그인 유도 | ✅ | ✅ |

## 비고

- 모임 검색은 `GET /api/clubs/search` (permitAll) 기반, 비로그인도 가능
- 모임 추천은 `GET /api/clubs/recommendations` (authenticated) 기반, 비로그인 시 로그인 유도
- 모임 생성은 로그인 멤버라면 누구나 가능 (개설자가 됨)
- 내 모임 목록은 `GET /api/me/clubs` (authenticated) 기반, 로그인 시에만 표시
