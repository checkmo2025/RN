| 역할 | 설명 |

## 비고

- 화면 자체는 비로그인도 진입 가능하나, 탭 콘텐츠 전체에 `isLoggedIn` 가드 적용 → "로그인이 필요해요" 프롬프트 표시
- `GET /api/members/my/profile`, `GET /api/members/my/clubs` 등 `/api/members/my/**` 전부 authenticated 필요
- `GET /api/notifications/**` — authenticated, 비로그인 호출 없음
- 설정 아이콘(`⚙`) 클릭 시 `requireAuth()` 게이트 적용 → 비로그인이면 로그인 유도 후 진입
- 관리자 전용 기능 없음 (관리자도 일반 멤버와 동일하게 사용)
