# 홈 화면 접근 권한 (`HomeScreen`)

## 역할 범위

| 역할 | 설명 |
|------|------|
| 사용자 | 회원가입 하지 않은 사람 |
| 멤버 | 회원가입을 한 사람 |
| 관리자 | 책모의 관리자 |

---

## 기능별 권한

| 기능 | 사용자 | 멤버 | 관리자 |
|------|:------:|:----:|:------:|
| 화면 진입 | ✅ | ✅ | ✅ |
| 소식 캐러셀 조회 | ✅ | ✅ | ✅ |
| 소식 상세 이동 | ✅ | ✅ | ✅ |
| 사용자 추천 카드 조회 | ❌ 미표시 | ✅ | ✅ |
| 사용자 프로필 이동 | ✅ | ✅ | ✅ |
| 구독 토글 | ❌ 로그인 유도 | ✅ | ✅ |
| 책이야기 피드 조회 | ✅ | ✅ | ✅ |
| 책이야기 상세 이동 | ✅ | ✅ | ✅ |
| 책이야기 좋아요 토글 | ❌ 로그인 유도 | ✅ | ✅ |
| 책이야기 댓글 포커스 이동 | ✅ | ✅ | ✅ |

## 비고

- 소식 캐러셀은 `GET /api/news` (permitAll) 기반으로 비로그인도 조회 가능
- 사용자 추천은 `GET /api/members/recommended` (authenticated) 기반으로 로그인 시에만 표시
- 책이야기 피드는 `GET /api/book-stories` (permitAll) 기반으로 비로그인도 조회 가능
- 좋아요/구독 액션은 로그인 유도 후 처리
