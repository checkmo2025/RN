Core Features

책모의 핵심 기능

독서 모임 운영에 필요한 모든 것을 하나의 앱에서. 읽고, 쓰고, 모이고, 나누는 독서 생활의 완성.

01

책 이야기

읽은 책에 대한 감상과 생각을 자유롭게 나누세요. 전체 피드, 구독 피드, 모임별 피드로 원하는 이야기를 탐색하고, 좋아요와 댓글로 소통할 수 있습니다.

글 작성·수정 좋아요·구독 댓글·대댓글 공유하기 책 검색
02

독서 모임

나만의 독서 모임을 생성하거나 관심 있는 모임에 참여하세요. 공지사항, 책장, 정기 모임, 조별 활동까지 모임 운영의 모든 기능을 제공합니다.

모임 생성 공지·투표 책장 관리 조별 채팅 운영진 관리
03

소식 & 마이페이지

책모의 최신 소식과 추천 도서를 확인하고, 내 프로필과 서재를 관리하세요. 알림 설정, 팔로우 관리, 계정 설정까지 한 곳에서 편리하게.

소식 캐러셀 추천 도서 내 서재 팔로우 관리 알림 설정
04

웹 서비스 & 관리자

Next.js 16 기반의 웹 프론트엔드로 브라우저에서도 책모를 이용하세요. SSR과 SEO 최적화로 검색 엔진 노출을 극대화하고, 관리자 대시보드에서 소식·모임·회원을 통합 관리할 수 있습니다.

SSR / SEO 관리자 대시보드 소셜 로그인 반응형 디자인 Framer Motion
Feature Details

상세 기능 살펴보기

책모가 제공하는 세심한 기능들로 더 풍성한 독서 경험을 만나보세요.

🔐

안전한 인증 시스템

이메일 인증 기반 회원가입, 자동 토큰 갱신, 안전한 세션 관리로 편리하고 안전한 로그인 경험을 제공합니다.

📖

책 검색 & 서재

외부 도서 API와 연동된 검색으로 원하는 책을 빠르게 찾고, 좋아요로 내 서재에 담아 관리할 수 있습니다.

💬

실시간 조별 채팅

STOMP 기반 웹소켓으로 조별 실시간 채팅을 지원합니다. 정기 모임의 조원들과 즉시 소통하세요.

🗳️

공지 투표 기능

단일·중복 투표, 익명·실명 투표를 지원하는 공지 투표로 모임 운영의 의사결정을 쉽게 만들어줍니다.

📋

발제 & 한줄평

책장별로 발제문을 공유하고 별점과 함께 한줄평을 남길 수 있습니다. 조별 발제 진행 상태도 한 눈에 확인됩니다.

🔔

맞춤 알림 관리

좋아요, 댓글, 모임 활동 등 세분화된 알림 설정으로 중요한 소식만 선별해서 받아보세요.

🌐

SSR & SEO 최적화

Next.js 16의 서버 사이드 렌더링으로 빠른 초기 로딩과 검색 엔진 최적화를 동시에 달성합니다. 동적 사이트맵과 메타 태그를 자동 생성합니다.

👨‍💼

관리자 대시보드

소식 관리, 모임 관리, 회원 관리, 책 이야기 관리를 하나의 웹 대시보드에서 통합 운영합니다. 관리자 전용 인증과 레이아웃을 제공합니다.

🔑

소셜 로그인

Google, Kakao, Naver OAuth2 연동으로 간편한 소셜 로그인을 지원합니다. Apple 로그인도 기획 단계에 있습니다.

Platforms
