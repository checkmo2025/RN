## 2. 변경 전

책장 상세 한줄평을 루트 목록의 헤더 안에서 `map()`으로 모두 생성했다. 한줄평 수가 늘수록
작성자·별점 아이콘 5개·본문을 포함한 카드 전체가 첫 커밋에 포함됐다.

```tsx
<View style={styles.bookshelfPostList}>
  {bookshelfReviewItems.map((item) => (
    <View key={item.id} style={styles.bookshelfPostCard}>
      {/* 작성자·메뉴·별점 5개·본문 */}
    </View>
  ))}
</View>
```

## 3. 가설·근거·기대 결과

### 가설

발제와 공지가 이미 사용하는 모임 화면의 루트 `FlatList`에 한줄평도 연결하면 화면 주변 카드만
생성된다. 한줄평이 많을수록 첫 커밋 시간과 초기 렌더 수가 감소하고, 실제 행 JSX·배열·상태를
그대로 이동하므로 사용자 동작은 유지될 것이다.

### 근거

- `bookshelfReviewItems.map()`은 한줄평 카드와 카드당 별 아이콘 5개를 모두 즉시 생성했다.
- 내부 `FlatList` 추가는 같은 방향의 루트 목록과 중첩되므로 기존 루트 목록을 재사용해야 한다.
- 앞선 발제 가상화로 루트 목록에 책장 상세 항목을 안전하게 연결하는 구조가 이미 있다.
- React Native 기본 `FlatList`를 사용하므로 새 의존성이 필요 없다.

## 4. 변경 후

```tsx
const groupHomeListItems = showVirtualizedBookshelfReviews
  ? bookshelfReviewItems
  : previousItems;

<FlatList
  data={groupHomeListItems}
  keyExtractor={(item) => item.id}
  renderItem={({ item }) =>
    item.type === 'REVIEW'
      ? <GroupBookshelfReviewRow item={item} {...handlers} />
      : <GroupBookshelfTopicRow item={item} {...handlers} />
  }
  ListFooterComponent={
    showVirtualizedBookshelfReviews ? <GroupBookshelfReviewFooter {...state} /> : previousFooter

/>
```
