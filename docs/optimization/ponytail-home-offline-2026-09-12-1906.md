## 3. 가설·근거·기대 결과

### 가설

첫 페이지 성공 전과 실패 후에 추가 페이지를 차단하고 모든 목록 요청에 공통 진행 상태 검사를 적용하면 반복 요청과 로딩 재진입을 막을 수 있다.

### 근거

- 하단 로딩 표시의 높이 변화는 빈 FlatList의 끝 도달 이벤트를 재발생시킬 수 있다.
- 기존 catch는 다음 페이지 가능 여부를 그대로 두고 로딩 상태만 해제한다.
- 기존 ref, 오류 resolver, FeedbackPressable을 재사용하면 새 의존성 없이 해결할 수 있다.

### 기대 결과와 성공 기준

| 지표 | 기준값 | 목표값 | 성공 조건 |
| --- | ---: | ---: | --- |
| 실패 후 끝 도달 이벤트 20회 | 요청 21회 | 1회 | 추가 자동 요청 없음 |
| 최초 요청 중 추가 요청 | 요청 2회 | 1회 | 동시 목록 요청 없음 |
| 복구 뒤 새로고침·페이지 추가 | 기존 정상 결과 | 같은 ID·순서 | 중복 제거·커서 유지 |
