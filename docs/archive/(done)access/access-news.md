# 소식 화면 접근 권한 (`NewsScreen`)

## 역할 범위

| 역할 | 설명 |
|------|------|
| 사용자 | 회원가입 하지 않은 사람 |
| 멤버 | 회원가입을 한 사람 |
| 관리자 | 책모의 관리자 |

---

## 기능별 권한

| 기능 | 사용자 | 멤버 | 관리자 |
|------|:------:|:----:|:------:|
| 화면 진입 | ✅ | ✅ | ✅ |
| 소식 캐러셀 조회 | ✅ | ✅ | ✅ |
| 소식 목록 조회 | ✅ | ✅ | ✅ |
| 소식 상세 조회 | ✅ | ✅ | ✅ |
| 원문 보기 (외부 링크) | ✅ | ✅ | ✅ |
| 오늘의 추천 책 조회 | ✅ | ✅ | ✅ |
| 추천 책 상세 이동 | ✅ | ✅ | ✅ |
| 문의하기 (FAB) | ✅ | ✅ | ✅ |
| 소식 작성/수정/삭제 | ❌ | ❌ | ✅ (admin API) |

## 비고

- `GET /api/news`, `GET /api/news/{id}` — permitAll, 모두 조회 가능
- 소식 CUD는 `POST/PATCH/DELETE /api/admin/news/**` — `@PreAuthorize("hasRole('ADMIN')")` 적용, 관리자 전용
- `GET /api/news/me` — authenticated, 내가 등록한 소식 (관리자 기능)
