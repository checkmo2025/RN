# 모임 내부 접근 권한 (`GroupHomeView`)

## 역할 범위

| 역할 | 설명 |
|------|------|
| 사용자 | 회원가입 하지 않은 사람 |
| 멤버 | 회원가입을 한 사람 (해당 클럽 비가입) |
| 회원 | 회원가입을 했고, 해당 독서 클럽의 회원 (`MEMBER`) |
| 운영진 | 해당 독서 클럽의 운영진 (`STAFF`) |
| 개설자 | 해당 독서 클럽의 최고 관리자 (`OWNER`) |
| 관리자 | 책모의 관리자 |

## 비고

- `GET /api/clubs/{clubId}/home`, `GET /api/clubs/{clubId}/notices/latest` — permitAll, 비로그인 조회 가능
- `GET /api/clubs/{clubId}/me` — authenticated, 비로그인 호출 없음 (RN에서 `isLoggedIn` 가드 처리)
- 공지/책장 목록은 클럽 회원(MEMBER 이상)만 조회 가능 (`403` → 회원 안내 문구 표시)
- 운영진 = `STAFF` 또는 `OWNER`, 개설자 = `OWNER` 전용
- 모임 삭제는 개설자(`OWNER`)만 가능
