## 역할 범위

| 역할 | 설명 |
|------|------|
| 사용자 | 회원가입 하지 않은 사람 |

## 비고

- `GET /api/book-stories`, `GET /api/book-stories/{id}` — permitAll, 비로그인도 조회 가능
- `GET /api/book-stories/following`, `GET /api/book-stories/clubs/**` — authenticated, 로그인 필요
- 글/댓글 수정·삭제는 서비스 레이어에서 `memberId` 비교로 작성자 본인만 가능
- 관리자는 `DELETE /api/admin/book-stories/**` 경로로 별도 처리
