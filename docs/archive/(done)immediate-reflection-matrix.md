# 좋아요/구독/생성 액션 즉시 반영 현황 (전 페이지)

## 기준
- `즉시(낙관적)`: API 응답 전에 화면 상태를 먼저 바꿈. 실패 시 롤백.
- `성공 후`: API 성공 뒤 화면 상태를 바꿈.
- `성공 후 재조회`: API 성공 뒤 목록/상세를 다시 조회해 반영.
- `즉시 반영 없음`: 호출 후 현재 화면에서 바로 값이 안 바뀜.

검토 대상 페이지:
- `HomeScreen`
- `StoryScreen`
- `MeetingScreen`
- `MyPageScreen`
- `UserProfileScreen`
- `NewsScreen`
- `AuthFlowScreen`
- 공통 헤더 `AppHeader`

## 한 줄 결론
- **즉시(낙관적) 반영이 강한 화면**: `Home`, `Story`, `MyPage(일부)`, `UserProfile(팔로우 목록)`, `AppHeader`.
- **성공 후/재조회 중심 화면**: `Meeting` 전반, `UserProfile 상단 구독`, `AuthFlow`.
- **즉시 반영 취약 포인트**: `MyPage`의 내 서재 `좋아요 해제`는 현재 화면에서 바로 빠지지 않고 새로고침 의존.
